## 重新生成

在本目录执行：

```bash
python3 -m pip install -r 11_源码_python生成脚本/requirements_v14.txt
python3 11_源码_python生成脚本/build_v14_reports.py
python3 11_源码_python生成脚本/validate_v14_reports.py
```

脚本使用相对目录，不依赖原始Downloads路径；会生成主报告、事实审计表、机构简版、完整重排版、300页级超全景版、12个旧版式维护版和合成Markdown源。维护版使用`09_历史冻结基线/`内的只读PDF作为构建输入。WeasyPrint在macOS上还需要Pango、GLib等系统库；依赖版本已锁定，避免分页与PDF对象处理随环境漂移。

超全景版的卷首顺序固定为：V1.4正式封面、完整免责声明、动态总目录、V1.4更新正文，随后衔接V1.3.4冻结历史正文。当前卷首共22页；总目录根据本次实际分页动态生成，免责声明不再插在V1.4与V1.3修订说明之间。
