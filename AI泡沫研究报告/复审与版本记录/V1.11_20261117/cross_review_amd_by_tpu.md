# TPU研究线对AMD材料的独立互审

审查日：2026年11月17日（北京时间）。审查对象：同目录amd_research.md；重点为A09信用支持、期限与付款人风险。未修改AMD文件，不将此记录视为全报告、英文或每一财务金额的全面审计。

结论：所审部分未发现重大错误。AMD材料正确分开算力采购承诺、拟转租机房租赁、违约触发担保与自营采购义务；共同终端客户风险与供应商技术多元化的区别表达清楚。建议保留以下可核边界。

| 已查项目 | 原件定位与结论 | 应保留限制 |
|---|---|---|
| 对外算力承诺 | Note11表格为$6.175B，按十亿美元一位小数为6.2；第三方客户付款会抵减最大义务 | 不是当期全部现金支出，也不等于最终净代偿。FY26剩余及FY27计划合计$1.515B，长期总额与近期付款分开 |
| 拟转让/转租未起租机房 | Note11为$13.3B，10–15年，预计FY27Q2开始 | 是未来租赁义务，不是客户债务担保；已转租部分在Note10仍以AMD为原租赁主要义务人 |
| 租赁担保 | Note8最大毛敞口$7.7B、最长15年，随商业伙伴付款递减 | 对手违约触发；可承担、转让或转租底层租赁；不等于无回收损失 |
| 债务担保 | Note8最大毛敞口$0.75B、最长6个月 | 6个月只适用于该债务担保；不是全部担保的统一到期日 |
| 已发生代偿 | Note8明确截至9月26日无商业伙伴违约、无担保支付 | 仅为期末状态，不能推出以后风险为零 |
| 自营采购 | Note11总$48.761B，包含晶圆、内存、制造服务及内部研发等 | 与对外生态支持分列，不合成一种“救助资金” |
| 共同客户预算 | AMD分析明确OpenAI、Meta、Anthropic及云预算可以同时传导多硬件 | 份额上升可与收入下降并存，属于条件经济推论，不是已发生行业收缩 |
| TPU与AMD关系 | TPU 8tx用EPYC主机 | CPU配套不等于Instinct取得同等加速器份额；两代理稿均已保留 |

直接核验原件：[AMD 2026Q3 10-Q](https://www.sec.gov/Archives/edgar/data/2488/000000248826000191/amd-20260926.htm)，Notes8、10、11及Liquidity and Capital Resources。审查依据是对同一原件的独立阅读，不是取得第二套独立财务账簿。

已向AMD作者发送两项可选增强：用$1.515B近期算力付款说明期限；注明转租后主要义务可能留存。未要求机械相加全部未来承诺，也未要求不必要扩大公司史。
