## 三、分层更新：可以改变什么，不能跨越什么

| 判断层级 | 本事件允许的即时更新 | 进一步结论所需证据 | 正式草稿应避免的跳跃 |
|---|---|---|---|
| 人事与决策结构 | 更新职务、临时安排、正式继任尚待完成的事实 | 人员权限、继任进展、决策流程及实际执行情况 | 把正式职务退出写成已彻底退出所有影响或所有持股 |
| 关键人与执行风险 | 新增战略协调、客户沟通、组织连续性的压力情景；提高核查优先级 | 核心人员流动、路线图延误、交付与客户行为 | 把创始人影响力等同于全部技术、客户关系与公司价值 |
| 治理质量 | 将治理假设标为待复核，分别记录监督机制与执行风险 | 调查结论、权限与监督实际效果、资本配置及披露质量 | 一概认定治理恶化；也不能因增设董事长就认定治理已经改善 |

| NVIDIA客户融资与支持 | 提高对已承诺资金、未承诺资金和新交易审批的关注 | 实际条款变更、提款限制、资金到账、撤回或取消通知 | 将CEO离任视为所有投资、担保或客户授信自动终止 |
| 模型公司与算力项目偿付 | 将依赖未来融资的主体列入观察 | 可用资金、到期硬付款、期后收款、融资净所得及用途限制 | 把融资讨论推迟等同资金链断裂，或把全部授信额度当已到账现金 |
| 跨主体信用传导 | 画出待验证路径，明确中止点 | 多个实际承担不同风险的主体，出现可追踪的付款、授信、抵押或订单恶化 | 以多个媒体报道、关联公司重复口径或股票共跌冒充独立传导证据 |
| 主要风险窗口 | 当前维持原窗口，并单列本次事件观察 | 新证据足以改变资金缺口发生时间和跨主体扩散判断 | 仅因重大新闻提前窗口，或补写已发生事件为预言命中 |
| 技术与终端需求 | 保持能力、采用、付费和资本回收分开 | 相同质量任务的成本、付费用量、续费及客户收益 | 用辞职否定技术价值；用技术持续发布反证任何资本风险 |

最需要防止的语义滑移是：从“原先依赖关键人的假设需要检验”，滑到“公司无法运行”；再从“市场可能重估”，滑到“客户已融资失败”。各层之间没有自动成立的等号。

## 四、把最强看空链条拆成可证伪步骤

可以提出的严肃风险假说是：领导层变化和相关不确定性，使部分资金提供者重新审查新增支持；若因此减少可用融资，而客户已有付款不能同步下调，流动性缺口可能沿订单与担保扩散。这是一条条件链，不是对现状的断言。

| 待验证环节 | 最低可检查材料 | 能中止或削弱该环节的情况 |
|---|---|---|
| 交接改变资本配置或信用支持 | 董事会或公司披露的政策变更、具体投资/信用交易处理 | 既有承诺履行，审批与出资正常，治理监督改善且执行连续 |
| 资金提供者收紧实际供给 | 可比融资条款、已满足条件的提款变化、承销或贷款文件、实际到账 | 长期资金落实、资金提供者替代、期限与付款匹配改善 |
| 客户出现净资金缺口 | 同期可动用现金、实际回款和未重复计入的到期付款 | 付款延期、可取消扩建、经营回款增加，足以弥补净缺口 |
| 缺口影响采购、资产与其他主体 | 取消或延后订单、逾期账款、担保触发、抵押要求及对应主体 | 原合同仍履行，调整限于单笔业务且未向其他主体扩散 |
| 原论文定义的较大范围破裂 | 持续多主体重定价，投资、融资与回收压力共同印证 | 价格冲击短暂，交付和现金改善，其他主体融资与运营保持稳定 |

证据包至少应给出：受影响主体、原基准、变化日期、金额或条款、真实现金影响、其他可能原因，以及可推翻结论的后续观察。不能用“信心受损”代替中间几环的材料。

归因还要防止三类重复：辞职和此前的负面披露可能来自同一原因，不能当两个独立证据加权；应收、客户贷款与担保可能指向同一付款风险，不能各计一次全部损失；估值模型若已纳入较高资本成本，就不能再无依据叠加一次完整“信心折价”。

供应商与客户的资产负债也应分账：NVIDIA侧先核库存、应收、采购承诺和客户支持义务；客户已购GPU的折旧、减值、租金及抵押价值属于客户侧问题。离任不会使客户GPU同日经济报废，也不会自动在NVIDIA账上新增同额设备折旧。发生退货、信用损失或担保触发时，再按对应合同与报表确认传导。

监管变量另建时间线。主研究员发现的BIS材料需区分预公示、正式刊登与生效时间及适用范围；若截至日仍未生效，就只能讨论其预期或拟议执行影响，不能写成已实施的订单禁令。市场与融资同时面对监管变化时，更不能把所有反应归因于CEO辞职。

| 待退回表述 | 不成立之处 | 可接受的改写方向 |
|---|---|---|
| “辞职证明财务造假/融资骗局” | 人事事实不是交易真实性、收入确认或欺诈意图的证明 | 分别核查特定交易、会计处理及调查结论；没有结论就标为待证 |
| “黄仁勋离开，循环融资必然断裂” | 公司主体、已签合同、董事会及客户资金来源均不能归约为个人 | 区分既有法律义务、可撤回支持、未来新增交易与实际付款 |
| “股价大跌，所以我们的泡沫预测已经命中” | 偷换了原论文的多主体、持续性及资金经营传导条件 | 记录市场事件，保留未满足条件，继续观察 |
| “2026年11月就是原文提前情景，因此应提前基准” | 日期吻合不证明信用路径发生 | 原情景继续有效；新增合同或现金证据才支持更新 |
| “事件越大，泡沫越确定；再延后一定跌更多” | 没有校准概率，且忽略资金、支出和回款可改善 | 仅在净硬义务相对回款恶化时上调相应压力假设 |
| “GPU折旧将再吞噬同额现金” | 已扣设备资本支出后再扣折旧会重复计算 | 分开利润成本、当期现金及未来更新支出 |
| “所有GPU三年失效” | 技术代际不能替代设备批次的经济寿命与残值 | 核查租金、利用率、维护及转用现金 |
| “辞职说明应用市场终究受旧TAM硬上限约束” | 管理变更与市场容量不是同一命题，且旧硬上限已撤回 | 保留按量、长任务、非专业用途等收费边界的修正 |

监管调查、诉讼、董事会独立调查与最后认定也须分层。后续研究即使核实存在调查，仍不能将“正在调查”替换为“已认定违法”，也不能将公司否认替换为已完成独立排除。

## 六、看空判断必须接受的缓冲与反证

反证的强弱取决于它推翻哪一层判断，不必要求一次证明整个行业安全。

- **组织连续性：** 继任安排顺利，关键团队稳定，已承诺产品与交付完成，会削弱“关键人离开导致执行失灵”的判断。公告承诺只提供观察起点，实际完成才是较强证据。
- **融资连续性：** 资金按期到账、可用期限延长、条款未恶化、已承诺付款可覆盖，会削弱近期信用冲击判断。它证明流动性缓冲，仍不自动证明项目经营回本。
- **需求与回款：** 终端客户用经营预算持续复购，促销退出后净回款与现金毛利改善，会直接削弱“需求依赖下一轮融资”的判断。不能把所有新增收入预先归为循环融资。
- **主动消化：** 未承诺扩建有序放缓、取消代价可承受、既有资产利用率和现金改善，会削弱“延迟即放大”。削减CapEx可能伤害设备商增量订单，却同时改善下游资产回收，不能只保留悲观一面。
- **旧资产继续回收：** 实现租金、成本与转用后净现金足以支持原回收计划，会削弱经济寿命过短的假说；不能因旧GPU未报废就宣布全部投资成功。
- **治理改善：** 交接若提高投资纪律、透明度与风险控制，并减少低回报承诺，可能改善资金效率。该方向同样需要行为证据，不因正式增设职位就视为已经实现。
- **无跨主体扩散：** 单家公司治理风险被隔离，其他企业的融资、付款与订单稳定，足以否定“已经发生行业性信用收缩”，但并不证明未来永无风险。

最强反证组合是：经营回款追赶、旧资产持续贡献现金、净新增硬付款放缓且融资依赖下降。它出现时应转向消化判断，不能改称“泡沫隐藏得更深”。

## 七、正式稿的验收口径

正式稿需要同时通过以下检查：

1. 每条新增事实有可打开的一手来源，事实、公司表态、作者推断与待证假说分明；北京时间截止日处理正确。
2. 解释清楚人事事实更新了哪些具体假设，不用重大程度替代传导证据。
3. 不把股价变化写成现金变化，不把融资承诺写成到账，不把集团现金写成特定AI资产已回本。
4. 对任何风险窗口调整，同时保存原登记日、条件与结算日；如证据只够提高观察优先级，就明确不改窗口。
5. 披露目前缺失的合同或信用材料，缺失不能被填为利空或利好；不创造固定概率、跌幅或统一资产寿命。
6. 列出至少一条会实质削弱核心看空链条的可观察路径，并说明出现后改哪项结论。
7. 结论允许公司分化：NVIDIA估值、客户流动性、应用采用和旧资本回收可以朝不同方向变化。

建议正式稿可采用的核心判断：

> 黄仁勋辞职使我们必须单独审视NVIDIA的继任、关键人依赖与资本配置连续性。它可能改变市场要求的风险补偿，但仅凭人事公告，尚不能确认客户融资收缩或资本循环已断裂。当前保留2027年上半年至2028年上半年的原主观风险窗口及2028年6月30日结算约束；提前信用冲击情景仍须由实际付款、融资条件和跨主体传导验证。若交接平稳、资金按期落实、经营回款改善且新增硬付款放缓，我们应降低相应风险判断，承认投入正在被消化。

本预审为正式草稿交叉复核的基线。收到治理/监管与融资合同证据及正式草稿后，应依据新材料审阅具体措辞；本稿不预先否定其他研究可能取得的实质性证据。
