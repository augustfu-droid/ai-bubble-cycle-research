# V1.9 主题承接与深化边界

资料截止2026年10月31日，北京时间。沿用[V1.8主题映射](V1.8_原339页主题覆盖表_20261031.md)及更早原339页研究主题，重点扩大专题三、四，其他主线保留。

| 主题 | V1.9处置 | 核验边界 |
|---|---|---|
| 短剧中美市场 | 保留已有收费、公司和成本证据，新增时长说法追源与视频模型产业链 | 全短剧不等于AI子集，手机时长不等于全端观影，播放不等于生成 |
| 视频模型与供应商 | 深研Seedance、MiniMax／海螺、可灵等产品、收费、财务和工作流 | 净标价不等于实际ARPU，集团毛利不等于视频或短剧毛利，内部调用不等于外部销售 |
| 编程预测与劳动 | 保留历史原稿裁决，深化任务、团队、招聘与现金成本 | 工时、产能、就业存量、招聘流量和工资现金各自计量；不补造全行业替代率 |
| 编程价值分配 | 条件模型联结客户ROI、工具/模型/云与软件价格 | 客户创造价值不全部变成供应商TAM，工资预算不是可全部攫取收入 |
| 其他应用 | 沿用V1.8专题五及已核反例 | 非本轮逐公司重新取证，保留各自期间和指标定义 |
| 利润、融资、中国传导、估值 | 沿用V1.8已核财报、现金桥和日期；新模型财务在专题三处理 | 不把新增专题当全部公司的利润归因或估值模型 |
| AGI、国际、宏观、能源 | 保留V1.8核验范围，与深化专题交叉指引 | 独立实验与公司测试分开，模型能力、部署与回报不互换 |
| 风险情景、框架及跨境工具 | 保留机制、假设和原核验日 | 不生成新概率、崩盘日期或未经核验的交易价格 |
| 摘要、审计及20册版本 | 同步新结论与可用范围，重建书签及参考索引 | 不将全部版本的重复页数称为独立新增研究量 |

完整专题三、四进入主报告、全景、超全景、核心合集及商业化合卷，并有独立册。公开选编包含视频专题和编程概要；机构、摘要与执行版提供核心判断和检验方法。V1.8已交付文件与原Git历史文件由[V1.9保护基线](V1.9_拉取基线历史文件哈希_20261031.json)核验。
