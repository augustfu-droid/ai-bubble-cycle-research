## 现行研究框架

1. **利润与现金**：区分核心经营、投资重估、营运资本、现金资本开支与租赁本金。
2. **融资与合同**：沿法律实体和合同追踪资金、最低采购、可取消上限与担保，避免重复累计。
3. **商业化与技术**：分别验证收费、可持续毛利、技术能力、部署验收及资本回收。
4. **公司与估值**：将经营模型、现金流与资本结构接到估值，不把需求增长直接等同于股东收益。
5. **条件化情景**：列出风险触发、传导、反证和中止条件，不使用固定崩盘日期或未经校准的精确概率。
